# Liquid Companion · 液态玻璃前端（原设计开源版）

> 界面设计来自 @汪汪豆泥 的作品，她同意开源这份。感谢她。

iOS 液态玻璃风格的 AI 伴侣前端（React + Vite，手机优先，可以加到主屏当 App 用）。
这里只有**前端**，后端由你自己的服务提供，每页要哪些接口、返回什么，写在 `docs/` 里。

## 包含的页面

| 页面 | 路由 | 说明 |
|---|---|---|
| 首页 | `#/home` | 两屏左右滑：主页（头像、签名、统计、两张图卡、正在播放、继续阅读）+ 聊天框 |
| 聊天 | `#/chat`、`#/chat/<id>` | 聊天框列表、对话页（气泡、图片文件、链接卡、表态、思考过程、工具调用） |
| 音乐 | `#/music` | 音乐库 + 全屏播放器（歌词、队列），任何页面都能打开 |
| 工作室 | `#/studio` | 窗口和换窗、额度、机器、改动记录、文件、设置 |
| 设计系统 | — | `src/design/`：液态玻璃材质、令牌、通用组件、底部导航、迷你播放条 |

记忆页在原设计里有，但不在这份代码里，路由 `#/memory` 留了一个空页给你自己做。
`docs/` 里如果提到心潮、语音通话、外观设置，那几块也不在这份代码里，忽略就好。

## 跑起来

```bash
npm install
cp .env.example .env.local     # 填 VITE_API_BASE（你自己的后端地址）
npm run dev                    # 手机和电脑连同一个 Wi-Fi，用终端里显示的局域网地址打开
npm run build                  # 产物在 dist/，任何静态服务器都能托管
```

示例数据已经去掉：没接后端时页面显示「暂时连不上」。接上你自己的后端（接口见 `docs/`）就能用。

## 目录

```
src/
  design/         设计系统（玻璃、令牌、组件；页面只从 design/index.js 引入）
  theme/          壁纸、玻璃色调、气泡颜色（设置 → CSS 变量）
  components/     全屏播放器、首页聊天框
  lib/            接口出口 api.js、播放器状态、聊天、音乐、工作室数据
  pages/          首页、聊天、音乐、工作室
docs/             每页的接口说明
```
