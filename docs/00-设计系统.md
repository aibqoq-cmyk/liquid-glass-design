# 00 · 设计系统

整个前端只有一种材质：**液态玻璃**。所有颜色、透明度、模糊、圆角、动效都来自 `src/design/tokens.css`。
页面里只从 `src/design/index.js` 引入组件。

```jsx
import { Glass, Card, Button, IconButton, List, ListRow, Meter, Chip, Sheet } from '../design/index.js';
```

## 深色玻璃 / 浅色玻璃

同一套组件有两种外观，**自动切换，不用写两遍**：

| | 深色玻璃 | 浅色玻璃 |
|---|---|---|
| 什么时候 | 壁纸偏暗（晴空、黄昏、夜航），或用户选了深色玻璃 | 壁纸偏亮（奶糖、雪窗），或用户选了奶白 / 淡粉玻璃 |
| 文字 | 白字，带一点阴影 | 深暖棕字 `#4f3a3e`，无阴影 |
| 点缀 | `#ff8fb1` | `#f58fab` |

AppearanceProvider 算出亮度后给 `<html>` 加 `data-glass="light"` 或 `"dark"`，`tokens.css` 里整组语义色跟着换。
所以**组件里永远只写语义变量，不写死白色或深色**（见下表 `--track` `--fill-1` 等）。

## 三条硬规则

1. **玻璃里不要再套玻璃。** Safari 上嵌套的 `backdrop-filter` 会发灰。卡片里的次级块用 `.fill`（半透明填充），不要用 `<Glass>`。
2. **不写死颜色。** 玻璃的颜色由用户在「外观」里选，存在 CSS 变量里。新写的界面一律用 `<Glass>` / `.glass`，文字用 `var(--text-1/2/3)`，用户自己的气泡用 `var(--bubble)`。
3. **可点击的玻璃都要回弹。** 用 `<Glass pressable>`，或者给元素加 `className="pressable"`。手机上没有鼠标悬停，按下的弹簧回弹就是"液态"手感的来源。

## 令牌（`tokens.css`）

| 变量 | 作用 | 由谁写入 |
|---|---|---|
| `--glass-tint` | 玻璃颜色 `r, g, b` | AppearanceProvider（用户选的色调，或跟随壁纸自动算） |
| `--glass-alpha` | 玻璃浓度 0.15–0.70 | AppearanceProvider |
| `--glass-blur` | 磨砂 6–44px | AppearanceProvider |
| `--glass-thin-*` / `--glass-thick-*` | 薄/厚两档，自动按比例跟随上面三个值 | 自动 |
| `--glass-dark-*` | 深色玻璃（命令行），不跟随用户色调 | 固定 |
| `--ambient` | 壁纸的平均色，玻璃边缘高光会染上它 | AppearanceProvider |
| `--bubble` | 用户自己的消息气泡颜色 | AppearanceProvider |
| `--text-1/2/3` | 主/次/弱文字 | 随深浅玻璃切换 |
| `--accent` | 粉色点缀（未读数、表态） | 随深浅玻璃切换 |
| `--track` / `--bar-fill` | 进度条底 / 填充、开关关闭态 | 随深浅玻璃切换 |
| `--fill-1` / `--fill-2` | 卡片里的次级块 | 随深浅玻璃切换 |
| `--hairline` | 列表分隔线 | 随深浅玻璃切换 |
| `--tab-on` / `--badge-bg` / `--badge-ink` | 导航选中泡、角标 | 随深浅玻璃切换 |
| `--code-bg` | 命令行输出底色 | 随深浅玻璃切换 |
| `--sticker` | 壁纸手绘贴纸的线条色 | 随深浅玻璃切换 |
| `--spring` | 弹簧曲线（Safari 17.2+ 用真弹簧 `linear()`） | 固定 |
| `--safe-top` / `--safe-bottom` | 刘海和 Home 条的安全区 | 系统 |

用户开了系统的"减弱动态效果"时，所有动效会自动降级。

## 组件

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `Glass` | 一切玻璃的底材 | `variant`: thin / regular / thick / dark；`shape`: card / pill / circle；`pressable`；`as` |
| `Card` | 带内边距的标准卡片 | 同 Glass |
| `Button` | 胶囊按钮 | `tone`: glass / primary；`block`；`icon` |
| `IconButton` | 圆形图标按钮（返回、搜索、+） | `icon`、`label`（必填，读屏用）、`size`: md / sm |
| `SectionTitle` | 分区标题 | `icon`、`trailing` |
| `List` + `ListRow` | 设置页那种分组列表 | `icon`、`title`、`subtitle`、`onClick` / `href`（有就自动带箭头） |
| `Bar` / `Meter` | 进度条 / 带标签的进度条 | `value` 0–100，`warnAt` 默认 70 变橙，`dangerAt` 默认 90 变红 |
| `Chip` | 状态胶囊（SSH ●） | `status`: ok / off / busy / idle |
| `Badge` | 未读数 | `count` |
| `SearchField` | 玻璃搜索框 | `value`、`onChange(text)` |
| `Toggle` | iOS 开关 | `checked`、`onChange(bool)`、`label` |
| `Avatar` | 圆头像 | `src`、`size` |
| `TabBar` | 底部悬浮导航 | `tabs[{key,label,icon,badge}]`、`active`、`onChange` |
| `MiniPlayer` | 导航上方的迷你播放条，点了打开全屏播放器（`05-音乐.md`） | `track`（传 null 就隐藏）、`playing`、`onToggle`、`onNext`、`onOpen` |
| `Sheet` | 底部弹层（思考过程、命令行、来信、歌曲菜单） | `open`、`onClose`、`title`、`variant`；支持点遮罩、Esc、往下拖关闭 |
| `Wallpaper` | 全屏壁纸层（奶糖壁纸会带浮动的手绘贴纸） | 无，读外观设置 |

其他共用组件：`src/components/Faces.jsx`（没头像时的手绘小狗 / 兔子）、`src/components/chat-boxes/`（聊天框总览）、`src/components/tide-bottle/`（心潮瓶）。

图标统一用 `lucide-react`，描边 2px，和 SF Symbols 的观感最接近。

## 页面骨架

```jsx
export default function MyPage({ navigate }) {
  return (
    <main className="page">
      <h1 className="large-title">标题</h1>
      <SectionTitle icon={Server}>分区</SectionTitle>
      <Card>…</Card>
    </main>
  );
}
```

`.page` 已经处理好安全区和底部留白（给导航和播放条让位），新页面直接用。
在 `src/App.jsx` 的 `ROUTES` 里加一行就能挂上路由。

## iOS 注意事项

- 加到主屏后是全屏 PWA，状态栏透明，`index.html` 里的 meta 已经配好。
- 陀螺仪（心潮瓶倾斜）在 iOS 上必须在用户点击时授权。组件在第一次点瓶子时自动请求，不用额外处理。
- iOS Safari 不支持 `navigator.vibrate`，敲门的震动只在安卓生效，iOS 上静默跳过。
