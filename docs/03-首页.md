# 03 · 首页

路由 `#/home`（默认首页），`#/home?p=2` 直接打开第二屏。

首页三屏左右滑，像 iOS 桌面翻页。每一屏各自上下滚动，底部分页点可以点。

| 屏 | 内容 |
|---|---|
| ① 主页 | 两个头像、昵称签名、统计、两张图卡、正在播放、心潮入口、继续阅读 |
| ② 聊天框 | 他的每个窗口一个卡片，点进去聊天。详见 `04-聊天.md` |
| ③ 记忆 | 日历，和底部「记忆」标签同一个。详见 `07-记忆.md` |

首页不显示迷你播放条（第一屏自己有音乐卡），其余页面都显示。

## 接口契约

都是只读接口，失联时返回 `{ "available": false }`，对应卡片会隐藏或显示"暂时连不上"。

### `GET /api/profile` · 个人资料

```json
{
  "available": true,
  "name": "你们的名字",
  "handle": "your_handle",
  "verified": true,
  "bio": "一句签名",
  "tags": ["标签一", "标签二"],
  "avatars": { "ai": "https://…/ai.png", "me": "https://…/me.png" },
  "stats": [
    { "value": 115, "unit": "日", "label": "在一起", "href": null },
    { "value": 19, "unit": "冊", "label": "读过的书", "href": "#/reading" },
    { "value": 3, "unit": "枚", "label": "收集", "href": null }
  ],
  "cards": [
    { "image": "https://…/1.jpg", "alt": "说明文字", "href": null },
    { "image": "https://…/2.jpg", "alt": "说明文字", "href": null }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `avatars.ai` / `avatars.me` | 不给就显示手绘的小狗 / 兔子默认头像 |
| `stats` | 建议 3 项。`label` 不显示在界面上，读屏会念出来；有 `href` 就能点 |
| `cards` | 固定两张。没有图时显示"放一张图"的虚线占位；有 `href` 就能点 |

"在一起 N 日"建议后端按起始日期实时算，不要存死。

### `GET /api/reading` · 继续阅读

```json
{
  "available": true,
  "total": 19,
  "href": "https://…/全部书单",
  "items": [
    { "id": "b1", "title": "书名二", "cover": "https://…/cover.jpg", "href": null, "color": "#8a6a3c", "ink": "#f6ead2" }
  ]
}
```

没有封面图时用 `color`（书底色）和 `ink`（字色）生成一个纯文字的书封。`items` 为空时整张卡隐藏。

### 正在播放：`GET /api/music/now` · `POST /api/music/control`

首页音乐卡和全局迷你播放条共用一份状态（`src/lib/player.js`），前端每 5 秒同步一次，播放中进度条用本地时钟走。

```json
{
  "available": true,
  "playing": true,
  "position": 42,
  "track": {
    "id": "m1",
    "title": "Gravity",
    "artist": "Jai Wolf, JMR",
    "cover": "https://…/cover.jpg",
    "duration": 198,
    "lyric": "当前这一句歌词（可选）"
  }
}
```

没在放歌：`track` 为 `null`，音乐卡显示"现在没在放歌"，迷你播放条隐藏。

控制：`POST /api/music/control`，请求体：

| `action` | 其他字段 | 含义 |
|---|---|---|
| `toggle` | — | 播放 / 暂停 |
| `next` / `prev` | — | 下一首 / 上一首 |
| `seek` | `position`（秒） | 跳到某个位置（音乐卡的 ±10 秒按钮） |

返回最新的播放状态（结构同 `GET /api/music/now`）。返回 `{ "ok": true }` 也可以，前端会马上再拉一次。

这一版是"遥控器"模式：歌在哪里放由你的后端决定（电脑、音箱或音乐服务），前端只显示、只发指令。

点封面或歌名打开全屏播放器，卡片右上角的小图标进音乐库。完整的音乐接口（搜索、歌单、歌词、队列、更多控制指令）见 [05-音乐.md](05-音乐.md)。

### 心潮入口

第一屏的心潮小瓶读 `GET /api/mind/now`（见 `01-心潮.md`），点了进心潮页。

## 验收

- [ ] 资料接口不返回头像时显示默认头像，不出现裂图
- [ ] 音乐卡点播放，迷你播放条（去别的页看）状态同步
- [ ] 心潮小瓶的颜色跟心潮页的心情一致
- [ ] 换成晴空壁纸后整页自动变成白字深色玻璃
