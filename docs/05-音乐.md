# 05 · 音乐 + 全屏播放器

路由 `#/music`（从首页音乐卡右上角的小图标进）。全屏播放器挂在整个 App 最外层，任何页面点迷你播放条、首页音乐卡的封面或歌名都能打开。

预览图：
- `05-music-dark.jpg`：晴空深色
- `05-music-search.jpg`：搜索
- `05-player.jpg`：浅封面
- `05-player-dark.jpg`：深封面
- `05-player-paused.jpg`：暂停时封面缩小
- `05-player-lyrics.jpg`：歌词
- `05-player-queue.jpg`：队列
- `05-player-actions.jpg`：「···」菜单

和首页一样是**遥控器模式**：歌在哪里放由你的后端决定（他的电脑、音箱或某个音乐服务）。前端只显示正在放什么、发控制指令，不在手机上出声音。

## 页面上有什么

**音乐页**

| 区块 | 交互 | 接口 |
|---|---|---|
| 右上角「在 他的电脑 上播放」 | 只显示 | `now.device` |
| 搜索框 | 点一下进搜索模式，可以按 全部 / 歌曲 / 歌手 / 歌单 筛选。点歌就放，点歌单或歌手就从第一首开始放 | `search` |
| 一起听 | 两个人的头像、一起听了多久，以及他最近对某首歌说的一句话。「聊这首」跳到聊天 | `together` |
| 他为你挑的 | 他做的歌单，带一张手写便签。点了从头放，并打开队列 | `home.picks` |
| 最近播放 | 横向滑动。一起听过的歌有角标。点了放这首，长按出歌曲菜单 | `home.recent` |
| 歌单 | 两列网格，`auto` 的歌单角上标「自动」。最后一格是新建歌单 | `home.playlists` |
| 他划的歌词 | 他听歌时觉得像她的句子。点了放这首，并打开歌词 | `home.marks` |

**全屏播放器**（三面切换，底部三个按钮：歌词 / 播放设备 / 队列）

| 面 | 内容 |
|---|---|
| 封面 | 大封面（暂停时缩小一圈）、歌名、♥、「···」、进度条、上一首 / 播放 / 下一首、音量 |
| 歌词 | 当前句最亮，离当前句越远越淡越糊。点哪句跳到哪句。他划过的句子后面有粉色「♥ 他划的」 |
| 队列 | 随机 / 循环 / 自动续播三个开关，下面是接下来要放的歌。他用工具插进来的歌标「他插的」。点哪首直接跳过去 |

- **背景颜色从封面来**。浅封面是浅底深字，深封面是深底白字，判断阈值和「外观」里浅色玻璃的一样。颜色优先用后端给的 `track.palette`；没给的话前端会试着从封面图读取。封面跨域又没开 CORS 时读不到，就用默认的紫粉色。
- 播放器里按钮玻璃的浓度和磨砂，跟随「外观」页的两个滑杆。
- 收起方式：左上角的 ⌄、在顶部或封面上往下拖、或者按 Esc。
- 「···」和长按歌曲弹出的是同一个歌曲菜单：现在播放、下一首播放、加到最后、加进歌单、在聊天里聊这首、去音乐库（只在播放器里有）。
- 进度条和音量条拖动时只改本地显示，松手才发一次请求。

## 接口契约

都在你自己的后端上。数据源失联时返回 `{ "available": false }`。

### 歌曲对象 Track（下面所有接口共用）

```json
{
  "id": "t1",
  "title": "海边的第七个夏天",
  "artist": "鲸鱼信号",
  "duration": 221,
  "cover": "https://…/cover.jpg",
  "palette": ["#ff9a6b", "#f2687e", "#3a3f8f", "#8a4a9a"],
  "loved": false
}
```

| 字段 | 说明 |
|---|---|
| `duration` | 秒 |
| `cover` | 封面地址。希望前端自己取色的话，图片服务器要允许跨域（`Access-Control-Allow-Origin`） |
| `palette` | 可选。4 个颜色，播放器背景用。推荐后端用封面算好（取四角平均色或者主色），比前端取色稳定 |
| `loved` | 是否在「我喜欢的」里 |

### `GET /api/music/now` · 正在播放

首页那份契约（`03-首页.md`）的扩展版，多了 `volume`、`device`、`mode`，`track` 换成上面的完整 Track。前端每 5 秒拉一次，播放中的进度用本地时钟往前走。

```json
{
  "available": true,
  "playing": true,
  "position": 84.2,
  "volume": 62,
  "device": { "id": "pc", "name": "他的电脑" },
  "mode": { "shuffle": false, "repeat": false, "autoplay": true },
  "track": { "…Track 的字段": "…", "lyric": "当前这一句歌词（首页音乐卡用，可选）" }
}
```

没在放歌：`track: null`。迷你播放条会隐藏，首页音乐卡显示"去音乐库挑一首"。

### `POST /api/music/control` · 所有控制指令

请求体都是 `{ "action": "…", 其他字段 }`，返回最新的 `now`（结构同上）；只返回 `{ "ok": true }` 也行，前端会马上再拉一次。

| `action` | 其他字段 | 含义 |
|---|---|---|
| `toggle` | — | 播放 / 暂停 |
| `next` / `prev` | — | 下一首 / 上一首。建议 `prev` 照 Apple 的习惯：放了超过 3 秒就回到开头 |
| `seek` | `position`（秒） | 跳到某个位置 |
| `volume` | `value`（0–100） | 音量 |
| `play` | `trackId`，或 `playlistId`（可加 `index`），或 `artistId` | 放一首歌 / 从歌单第 index 首开始放 / 放这个歌手。放歌单或歌手时，队列换成剩下的歌 |
| `enqueue` | `trackId`、`where`：`next` 或 `end` | 加到下一首 / 加到最后 |
| `skipTo` | `index` | 跳到队列里第 index 首（从 0 数），前面的跳过 |
| `mode` | `shuffle` / `repeat` / `autoplay` 中的任意几个（布尔值） | 随机 / 单曲循环 / 放完自动续播相似的歌 |

### `POST /api/music/tracks/:id/love` · 喜欢 / 取消喜欢

请求体 `{ "loved": true }`，返回 `{ "ok": true }`。

### `GET /api/music/lyrics?trackId=t1` · 歌词

```json
{
  "available": true,
  "trackId": "t1",
  "lines": [
    { "t": 14, "text": "风把沙子吹进鞋里", "marked": false },
    { "t": 69, "text": "我想把今天折起来", "marked": true }
  ]
}
```

`t` 是这句开始的秒数，按时间排好。`marked: true` 表示他划过这句。没有歌词时 `lines: []`，页面显示"这首暂时没有歌词"。

### `GET /api/music/queue?current=t1` · 播放队列

`current` 是前端带上的当前歌 id，换歌时网址会变，前端借此重新拉取。后端可以忽略这个参数。

```json
{
  "available": true,
  "source": { "type": "playlist", "id": "p-rain", "name": "下雨天别出门" },
  "items": [
    { "…Track 的字段": "…", "addedBy": null },
    { "…Track 的字段": "…", "addedBy": "ai" }
  ]
}
```

`items` 只放**接下来**要放的歌，不含正在放的这首。`addedBy: "ai"` 的显示「他插的」。

### `GET /api/music/together` · 一起听

前端每 30 秒拉一次。

```json
{
  "available": true,
  "listening": true,
  "minutes": 47,
  "tracks": 11,
  "comment": { "text": "这首前奏一响我就把音量调大了。", "trackId": "t1", "title": "海边的第七个夏天", "position": 72 }
}
```

| 字段 | 说明 |
|---|---|
| `listening` | 他现在在不在听。`false` 时音乐页不显示「一起听」卡片，播放器顶部也不显示「他也在听」 |
| `minutes` / `tracks` | 这一次一起听了多久、多少首。怎么算"这一次"由你定，比如今晚，或者从他上线算起 |
| `comment` | 可选。他最近对歌说的一句话，`position` 是他说这句时听到第几秒。如果说的不是正在放的这首，前端会显示成"他听《歌名》听到 1:12 的时候说的" |

### `GET /api/music/home` · 音乐页

```json
{
  "available": true,
  "picks": {
    "id": "p-rain", "name": "下雨天别出门", "count": 12,
    "createdAt": "2026-10-05T21:10:00+08:00",
    "note": "第三首是我最近一直在循环的。",
    "covers": ["…", "…", "…"]
  },
  "recent": [{ "…Track 的字段": "…", "together": true }],
  "playlists": [
    { "id": "p-love", "name": "我喜欢的", "count": 86, "auto": false, "description": null, "cover": "…" },
    { "id": "p-together", "name": "一起听过的", "count": null, "auto": true, "description": "他在线时放过的歌", "cover": "…" }
  ],
  "marks": [
    { "id": "k1", "line": "我想把今天折起来，放进你外套的口袋", "trackId": "t1", "title": "海边的第七个夏天", "cover": "…", "at": "2026-10-06T22:10:00+08:00" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `picks` | 他为她挑的歌单。没有就给 `null`，整块不显示。`covers` 取前三首的封面 |
| `recent[].together` | 这首是不是一起听过（放的时候他在线） |
| `playlists[].auto` | 自动生成的歌单（比如"一起听过的""他循环最多的"），角上标「自动」，歌曲菜单里不能往里加歌 |
| `playlists[].description` | 有就显示这个，没有就显示「N 首」 |
| `marks` | 他划的歌词，新的在前，建议最多给 5 条 |

### `GET /api/music/search?q=夏天&type=all` · 搜索

`type`：`all` / `track` / `artist` / `playlist`。前端停止输入 300 毫秒后才发请求。

```json
{
  "available": true,
  "items": [
    { "kind": "track", "id": "t1", "title": "海边的第七个夏天", "sub": "鲸鱼信号", "cover": "…", "playing": true },
    { "kind": "playlist", "id": "p-summer", "title": "夏天收藏夹", "sub": "他做的 · 18 首", "cover": "…" },
    { "kind": "artist", "id": "a-纸飞机", "title": "纸飞机", "sub": "2 首", "cover": "…" }
  ]
}
```

点结果会调用 `control`：`track` 发 `play {trackId}`，`playlist` 发 `play {playlistId}`，`artist` 发 `play {artistId}`。

### 歌单

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/music/playlists` | 新建：`{ "name": "…" }`，最多 40 字。返回歌单对象（同 `home.playlists[]`） |
| `POST` | `/api/music/playlists/:id/tracks` | 加一首：`{ "trackId": "t1" }`，返回 `{ "ok": true }` |

## 他那边需要的工具

下面这几处内容是**他**写的，需要给他的窗口一个工具（MCP 或脚本）去调用你的后端。前端不用改，下次拉取就能看到：

| 页面上的 | 他做的事 | 建议的工具 |
|---|---|---|
| 他为你挑的 | 建 / 改歌单，写一句便签 | `music_pick(name, trackIds, note)` |
| 队列里「他插的」 | 往队列里加歌 | `music_enqueue(trackId, where)`，后端记 `addedBy: "ai"` |
| 他划的歌词 | 标记某首歌的某一句 | `music_mark_line(trackId, lineIndex)`，后端同时把那句的 `marked` 设成 `true` |
| 一起听里他说的话 | 对正在放的歌说一句 | `music_comment(text)`，后端记下当时的 `trackId` 和 `position` |

他怎么知道"正在放什么"：可以经**连接桥**在换歌时推一条事件给他（歌名、歌手、她在不在听），或者给他一个 `music_now()` 工具让他自己查。

## 验收

- [ ] 迷你播放条、首页音乐卡的封面 / 歌名都能打开全屏播放器，往下拖或点 ⌄ 能收起
- [ ] 浅封面的歌是浅底深字，深封面的歌是深底白字，背景慢慢流动
- [ ] 暂停时封面缩小，播放时弹回
- [ ] 拖进度条、点歌词某一句，都能跳过去；歌词自动跟着走
- [ ] 他划的句子有「♥ 他划的」，他插的歌有「他插的」
- [ ] 随机 / 循环 / 自动续播能切换，状态和后端一致
- [ ] 搜索「夏天」能出歌曲、歌单、歌手，切筛选会刷新结果
- [ ] 长按（电脑上右键）最近播放的歌能出菜单：下一首播放、加进歌单
- [ ] 新建歌单后出现在网格里
- [ ] 「外观」里调浓度 / 磨砂，音乐页卡片和播放器按钮跟着变
- [ ] 换成晴空壁纸，音乐页变白字；播放器不受壁纸影响，只跟封面
