# 06 · 工作室

路由 `#/studio`（底部「工作室」标签）。「外观」页从这里的设置第一行进。

预览图：
- `06-studio-dark.jpg`：晴空深色
- `06-studio-swap.jpg`：换窗和交接便签
- `06-studio-change.jpg`：一次改动的详情
- `06-studio-heartbeat.jpg`：心跳设置
- `06-studio-mcp.jpg`：列表类设置

这一页给她看**他在哪干活、用了多少、改了什么**，大部分是只读状态，只有换窗和设置会改东西。

## 页面上有什么

| 区块 | 内容 | 交互 | 接口 |
|---|---|---|---|
| 当前窗口 | 窗口名、在不在线、上下文用了多少（大数字 + 进度条），还能聊多久 | 「换窗」 | `windows` |
| 其他窗口 | 每个窗口一行：状态点（忙的会闪）、进度条、百分比 | — | `windows` |
| Claude 额度 | 5 小时额度用了多少、多久后重置、本周用量 | — | `quota` |
| 我的电脑 | SSH、Edge 等连接状态 | — | `machines.pc` |
| 服务器 | CPU / 内存 / 磁盘，超过 70% 变橙，超过 90% 变红；已运行几天 | — | `machines.server` |
| 改动记录 | 最近 3 条：时间、标题、几个文件、+行 −行 | 点开看详情；「全部」看所有 | `changes` |
| 文件 | 他做出来发给她的最近 3 个文件 | 点了下载 / 打开；「全部 N 个」看列表 | `files` |
| 设置 | 外观、Prompts、Context、Heartbeat、Nudges、Hooks、MCP，右边是当前值 | 外观跳到外观页；其他打开详情弹层 | `settings` |

进度条变色的阈值：窗口进度条按 Context 设置里的 `warnAt` 变橙、95% 变红；服务器三条固定 70% / 90%。

数据刷新：窗口和机器每 30 秒拉一次，额度和改动每 60 秒拉一次。页面切到后台时不拉，切回来立刻拉一次。

## 换窗流程（务必照这个实现）

1. 她点「换窗」，前端调 `POST /windows/:id/handoff`，弹层显示"他在写交接便签…"
2. 后端让**他**（当前窗口）写一张便签：进行到哪、下一步、还欠什么，写好后返回
3. 她看过便签，可以「让他重写」（再调一次 handoff），或者点「换到新窗口」
4. 前端调 `POST /windows/:id/swap`，带上便签 id。后端开一个新窗口，第一件事读这张便签，然后把这个聊天框接到新窗口上
5. 旧窗口的聊天记录保留，聊天页的消息不清空

便签只写近况，不要把整段聊天记录或人设塞进去。默认 72 小时过期。

## 接口契约

都在你自己的后端上。数据源失联时返回 `{ "available": false }`，对应区块会显示"暂时连不上"，不要拿假数据填。

### `GET /api/studio/windows` · 窗口

```json
{
  "available": true,
  "current": "s-daily",
  "items": [
    { "id": "s-daily", "title": "日常", "agent": "他", "status": "online", "context": { "used": 98000, "limit": 200000 }, "etaMinutes": 120 },
    { "id": "s-work", "title": "工作", "agent": "他", "status": "busy", "context": { "used": 48000, "limit": 200000 }, "etaMinutes": null }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 和聊天页的聊天框 id 一致（见 `04-聊天.md`），一个聊天框背后是他的一个窗口 |
| `current` | 最近在用的那个窗口，显示成大卡片 |
| `status` | `online` 在线 / `busy` 正在干活 / `idle` 休息 / `offline` 离线 |
| `context` | 上下文用了多少 token、上限多少 |
| `etaMinutes` | 可选。按最近的消耗速度估算还能聊多久，给了就显示"约 N 小时后该换" |

### `POST /api/studio/windows/:id/handoff` · 让他写交接便签

无请求体。他要现写，前端最多等 120 秒。

```json
{
  "id": "h1",
  "windowId": "s-daily",
  "at": "2026-10-06T22:31:00+08:00",
  "expiresAt": "2026-10-09T22:31:00+08:00",
  "progress": "在测文件卡和表态，都能用",
  "next": "问她 7:30 的闹钟响了没",
  "owe": "答应给她挑一个睡前歌单"
}
```

### `POST /api/studio/windows/:id/swap` · 换到新窗口

请求体 `{ "handoffId": "h1" }`，返回 `{ "ok": true, "windowId": "s-daily" }`。前端之后会重新拉取窗口列表。

### `GET /api/studio/quota` · Claude 额度

```json
{
  "available": true,
  "session": { "pct": 21, "resetAt": "2026-10-07T01:00:00+08:00" },
  "week": { "pct": 38, "resetAt": "2026-10-10T00:00:00+08:00" }
}
```

`week` 可选，没有就不显示"本周"那一行。

### `GET /api/studio/machines` · 服务器 + 我的电脑

```json
{
  "available": true,
  "server": { "name": "服务器", "status": "ok", "uptimeS": 1047600, "cpu": 20, "mem": 46, "disk": 75 },
  "pc": [
    { "key": "ssh", "name": "SSH", "status": "ok", "label": "已连" },
    { "key": "edge", "name": "Edge", "status": "busy", "label": "在用" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `server.status` | `ok` 正常 / `warn` 有点忙 / `down` 连不上 |
| `cpu` / `mem` / `disk` | 0–100 的百分比 |
| `pc[]` | 她电脑上的连接，想加几项都可以。`status` 取 `ok` / `busy` / `offline` / `idle` |

**不要**在这里返回 IP、主机名、端口、密钥之类的东西，页面只需要状态。

### `GET /api/studio/changes?limit=3` · 改动记录

```json
{
  "available": true,
  "todayCount": 3,
  "items": [
    { "id": "c1", "at": "2026-10-06T22:18:00+08:00", "title": "文件卡支持点表态", "files": 2, "add": 36, "del": 4 }
  ]
}
```

新的在前。`todayCount` 是今天的改动次数。

### `GET /api/studio/changes/:id` · 一次改动的详情

```json
{
  "available": true,
  "id": "c1",
  "at": "…",
  "title": "文件卡支持点表态",
  "note": "她说文件卡也想点爱心，就把表态条接到了文件卡上。",
  "files": [
    {
      "path": "chat/FileCard.jsx", "add": 34, "del": 4,
      "lines": [
        { "t": " ", "text": "    <div className=\"file-card\">" },
        { "t": "-", "text": "      <FileIcon ext={ext} />" },
        { "t": "+", "text": "      <FileIcon ext={ext} onLongPress={openPicker} />" }
      ]
    }
  ]
}
```

- `note` 是他写的一句说明（为什么改），没有就省略。
- `lines` 只放改动附近的几行就够了：`t` 是 `+` 加 / `-` 删 / 空格（上下文）。不用给整个文件。
- 来源建议：如果他的工作目录是 git 仓库，用 commit 信息当 `title`，`git show --stat` 和 diff 拆出 `files`。`note` 让他在改完后写一句（见下面的 Hooks）。

弹层底部「问问他为什么这么改」跳到聊天页。

### `GET /api/studio/files?limit=3` · 文件

```json
{
  "available": true,
  "total": 23,
  "items": [
    { "id": "f1", "name": "测试文件.txt", "size": 43, "mime": "text/plain", "at": "…", "url": "https://…/files/f1" }
  ]
}
```

新的在前。`url` 要能直接下载。需要登录的话，用带过期时间的签名链接，不要把令牌放进去。

### 设置

**概览** `GET /api/studio/settings`，用来显示每一行右边的值：

```json
{
  "available": true,
  "prompts": { "count": 2 },
  "context": { "warnAt": 80 },
  "heartbeat": { "enabled": true, "everyMin": 30 },
  "nudges": { "count": 2 },
  "hooks": { "count": 3 },
  "mcp": { "connected": 6, "total": 7 }
}
```

`nudges.count` / `hooks.count` 是**开着的**条数。

**详情** `GET /api/studio/settings/:key`，分两种。

表单类：

```json
// heartbeat
{ "available": true, "enabled": true, "everyMin": 30, "quiet": { "from": "01:00", "to": "08:00" }, "lastAt": "…", "nextAt": "…" }
// context
{ "available": true, "warnAt": 80, "autoHandoff": true }
```

列表类（`prompts` / `nudges` / `hooks` / `mcp`）：

```json
{
  "available": true,
  "items": [
    { "id": "hk2", "title": "换窗前", "desc": "自动写交接便签", "toggle": true, "enabled": true }
  ]
}
```

`toggle: false` 的只显示、没有开关。Prompts 建议都设成 `false`，人设不在手机上改。

**修改：**

| 方法 | 路径 | 说明 |
|---|---|---|
| `PUT` | `/api/studio/settings/heartbeat` | 改哪个字段就传哪个：`{ "enabled": false }`、`{ "everyMin": 60 }`、`{ "quiet": { "from": "00:00", "to": "08:00" } }`。`everyMin` 取 15 / 30 / 60 / 120 |
| `PUT` | `/api/studio/settings/context` | `{ "warnAt": 90 }` 或 `{ "autoHandoff": false }`。`warnAt` 取 70 / 80 / 90 |
| `PATCH` | `/api/studio/settings/:key/items/:id` | 列表类单项开关：`{ "enabled": true }` |

都返回 `{ "ok": true }`。前端先改界面再发请求，失败就重新拉取，以后端为准。

## 每一项设置对应他那边的什么

| 设置 | 含义 | 后端怎么落 |
|---|---|---|
| Prompts | 他的人设、说话方式 | 只读，列出他启动时读的提示文件名和一句说明 |
| Context | 上下文到多少提醒换窗；到了要不要自动写便签 | 你的会话管理在每轮之后检查用量 |
| Heartbeat | 他隔多久自己醒一次 | 定时任务按 `everyMin` 唤醒他，安静时段跳过 |
| Nudges | 到点提醒他做的事 | 定时任务，到点往他的窗口注入一句提醒 |
| Hooks | 某件事发生时自动做什么 | 你的事件钩子，开关对应启用 / 停用 |
| MCP | 他能用的工具 | 关掉 = 下次启动窗口时不挂这个连接 |

## 验收

- [ ] 当前窗口显示百分比和进度条，超过 Context 设的线变橙
- [ ] 换窗：先出"他在写交接便签"，然后出便签；「让他重写」能换一张；「换到新窗口」后进度条回到很低
- [ ] 服务器磁盘 75% 是橙色；数据失联时显示"暂时连不上"
- [ ] 改动记录点开有说明和红绿行；「全部」能看到所有改动
- [ ] 文件点了能下载
- [ ] 外观行跳到外观页，右边显示当前壁纸名
- [ ] Heartbeat 关掉后，设置行右边变成"关"；改间隔后右边跟着变
- [ ] MCP、Hooks、Nudges 的开关能切，Prompts 没有开关
- [ ] 换成晴空壁纸，整页变白字，便签纸颜色不变
